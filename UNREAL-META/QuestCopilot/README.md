# Quest Dev Copilot - Unreal Engine Plugin

**Professional AI-Powered Debugging Assistant for Quest VR Development**

## Overview

The Quest Dev Copilot plugin provides a native Unreal Engine interface for AI-powered error analysis and debugging assistance specifically designed for Quest VR development. This plugin integrates seamlessly with your Unreal Engine workflow to provide instant, intelligent solutions to common Quest development challenges.

## Installation

1. **Copy Plugin to Project**
   ```
   Copy the QuestCopilot folder to your project's Plugins directory:
   YourProject/Plugins/QuestCopilot/
   ```

2. **Enable Plugin**
   - Open your Unreal Engine project
   - Go to Edit > Plugins
   - Search for "Quest Dev Copilot"
   - Check the "Enabled" checkbox
   - Restart Unreal Engine

3. **Configure Backend** (Optional)
   - Set backend URL in plugin settings
   - Configure API keys if using cloud services
   - Plugin works offline by default

## Usage

### Opening the Plugin
- **Menu**: Window > Quest Dev Copilot
- **Toolbar**: Click the Quest Dev Copilot icon
- **Shortcut**: Ctrl+Shift+Q (customizable)

### Analyzing Logs
1. **Paste Log Content**: Copy error logs from Output Log and paste into the plugin
2. **Auto-Detection**: Plugin can automatically detect and load project logs
3. **Add Context**: Describe what you were doing when the error occurred
4. **Capture Screenshot**: Optional visual context for rendering issues
5. **Analyze**: Click "Analyze Logs" for AI-powered analysis
